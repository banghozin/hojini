# 콘서 CBT

콘텐츠 서비스 디자인 **주차별 예/복습 테스트**를 빈칸에 적어 보며 외우는 웹앱입니다.
2~7주차 문항을 쌓아 두고, 8주차엔 전 범위를 섞어서 한 번에 돌립니다.

- **서버 없음.** 정적 파일뿐이라 GitHub Pages, Vercel, Netlify 어디든 그대로 올라갑니다.
- **AI 없음.** 브라우저 안에서 전부 끝나므로 API 키도, 사용 한도도, 비용도 없습니다.
- 폰 브라우저에서 그대로 돌아가고, 한 번 열면 오프라인에서도 동작합니다.
- 링크를 받은 사람은 **로그인 없이** 바로 봅니다.

---

## 채점하지 않습니다

시험이 예/복습 테스트 문제 그대로 나오고, 답도 문장이 아니라
`무형성 - 가시화` 처럼 **키워드로 적는 형식**입니다. 그래서 이 앱은 채점하지 않습니다.

빈칸에 생각나는 대로 적어 보고 → **`정답 확인`** 을 누르면 → 칸마다 바로 아래에 정답이 나옵니다.
그 아래로 해설이 함께 펴집니다. 맞고 틀림을 따지지 않으므로 점수도 정답률도 없습니다.

비워 둔 채 눌러도 됩니다. 답이 안 떠오르면 그냥 확인하고 넘어가세요.

## 오답노트

문항 아래 **`오답노트로 보내기`** 를 누르면 그 문항이 오답노트에 담깁니다.
자동으로 담기지 않습니다. 헷갈렸다 싶은 것만 직접 골라 넣는 방식입니다.

담은 뒤 홈으로 나오면 **`오답노트만 풀기 (N)`** 버튼이 생깁니다. 담은 것만 모아서 다시 봅니다.
다시 눌러 빼거나, 홈 아래쪽 `오답노트 비우기` 로 한 번에 지웁니다.

오답노트는 그 사람 브라우저에만 저장되고 서버로 나가지 않습니다.

## 문항 출처

문항은 **주차별 예/복습 테스트 시험지에 있는 문제만** 담습니다.
강의자료에서 새 문제를 만들지 않습니다. 문제 문장과 번호를 시험지 그대로 옮겼습니다.

| 주차 | 시험지 | 카드 | 빈칸 | 답 출처 |
|---|---|---|---|---|
| 2주차 | 예/복습 테스트 10문항 | 6장 | 23칸 | 답지 |
| 3주차 | 복습 테스트 8문항 | 8장 | 26칸 | 강의자료 |

2주차는 시험지 10문항이 카드 6장인데, **3, 4번은 흐름도 하나에 든 빈칸 둘**이고
**5~8번은 표 한 세트**라 시험지처럼 묶었기 때문입니다.

3주차는 **답지가 따로 없어서** 강의자료를 기준으로 답을 맞췄습니다.
6번(인지적 측면)과 7번(행동적 측면)은 강의자료가 4가지로 딱 떨어지게 적어 두지 않아
묶는 방식에 따라 답이 갈릴 수 있습니다. 해당 문항 해설에 그 점을 적어 두었습니다.

## 배포

### GitHub Pages

```bash
git add .
git commit -m "콘서 CBT"
git push
```

저장소 → **Settings → Pages** → Source를 **Deploy from a branch**, 브랜치 `main` / 폴더 `/ (root)` → Save.
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다.

### Vercel

저장소를 import 하고 Framework Preset을 **Other**, Root Directory를 이 폴더로 두면 끝입니다.
빌드 명령은 비워 둡니다. 이후엔 `git push` 할 때마다 자동 반영됩니다.

## 주차 추가하기 (3~7주차)

**1.** `data/week03.js` 를 만듭니다. `week02.js` 를 복사해 고치는 게 빠릅니다.

```js
window.QUIZ_BANK = window.QUIZ_BANK || [];
window.QUIZ_BANK.push({
  week: 3,
  title: "예/복습 테스트",
  items: [
    {
      id: "w3-01", no: "1", tag: "주제",
      q: "문제 문장",
      blanks: [
        { label: "①", answer: "첫째 정답" },
        { label: "②", answer: "둘째 정답" }
      ],
      why: "해설"
    }
  ]
});
```

**2.** `index.html` 아래쪽에 한 줄 더합니다.

```html
<script src="data/week02.js"></script>
<script src="data/week03.js"></script>   <!-- 추가 -->
```

이게 전부입니다. 홈 화면에 `3주차` 칩이 자동으로 생기고, `종합 (전체)` 범위에도 자동으로 들어갑니다.

### 문항 형식

형식은 하나뿐입니다. 짧은 빈칸 여러 개.

| 필드 | 뜻 |
|---|---|
| `id` | 고유 (`w3-01`) |
| `no` | 시험지 번호 (`"1"`, `"3~4"`, `"5~8"`) |
| `tag` | 주제. 문항 위에 작게 붙습니다 |
| `q` | 문제 문장 |
| `blanks` | `[{ label, answer }, ...]` 칸 하나에 객체 하나 |
| `why` | 해설 |
| `layout` | `"pair"` 를 주면 칸을 둘씩 묶어 `왼쪽 → 오른쪽` 한 줄로 |

`label` 은 칸 앞에 붙는 이름입니다. `"①"` `"3번"` `"그래픽 디자인"` 처럼 시험지에 적힌 대로 쓰면 됩니다.
빈 문자열이면 라벨 없이 입력칸만 나옵니다.

`q` 와 `why` 에는 `<b>` `<i>` `<u>` `<br>` 을 쓸 수 있습니다. `<i>` 는 인용 블록으로 보입니다.

`layout: "pair"` 는 5~8번처럼 **속성과 대응 방안**을 나란히 적는 표에 씁니다.
`blanks` 를 앞에서부터 둘씩 짝지으므로 개수를 짝수로 맞춰 주세요.
좁은 화면에서는 두 칸이 자동으로 위아래로 놓입니다.

문항 순서는 **앱이 매번 섞습니다.** 빈칸 순서는 시험지 그대로 둡니다.

## 쓰는 법

**범위** 주차를 골라서 (여러 개 선택 가능), 또는 `종합 (전체)` 로 전 범위

**문항 수** 전체 / 10 / 20 (범위보다 큰 값은 자동으로 잠깁니다)

**오답노트만 풀기** 담아 둔 문항이 있으면 홈에 버튼이 생깁니다

풀이 중 오른쪽 위 `3/14` 를 누르면 문항 목록이 열려 아무 문항으로나 건너뜁니다.
PC에서는 `Enter` 로 정답 확인과 다음, `←` `→` 로 이동이 됩니다.
입력칸 안에서 `Enter` 를 눌러도 정답이 나옵니다.

적은 내용은 **저장되지 않습니다.** 새로고침하면 처음부터입니다.
브라우저에 남는 것은 고른 주차와 문항 수, 그리고 오답노트뿐입니다.
