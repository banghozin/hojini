# 콘서 CBT

콘텐츠 서비스 디자인 **주차별 예/복습 테스트**를 CBT처럼 푸는 웹앱입니다.
2~7주차 문항을 쌓아 두고, 8주차엔 전 범위를 섞어서 모의고사로 돌립니다.

- **서버 없음.** 정적 파일뿐이라 GitHub Pages · Vercel · Netlify 어디든 그대로 올라갑니다.
- **AI 없음.** 채점이 전부 브라우저 안에서 끝나므로 API 키도, 사용 한도도, 비용도 없습니다.
- 폰 브라우저에서 그대로 돌아가고, 한 번 열면 오프라인에서도 동작합니다.
- 링크를 받은 사람은 **로그인 없이** 바로 풉니다.

---

## 문항 출처

문항은 **주차별 예/복습 테스트 시험지에 있는 문제만** 담습니다.
강의자료에서 새 문제를 만들지 않습니다. 번호도 시험지와 같게 답니다.

현재 2주차 7항목(1 · 2 · 3 · 4 · 5~8 · 9 · 10)이 들어 있습니다.
서술형이던 것을 고르는 형식으로만 바꿨고, 오답 보기는 헷갈리기 쉬운 것으로 채웠습니다.

> 예: 1번 ‘서비스의 속성 4가지’ 보기에 **동질성**(이질성의 반대), **지속성**(소멸성의 반대),
> **가시성**(대응 방안인 ‘가시화’와 혼동), **표준성**을 함께 넣었습니다.

## 배포

### GitHub Pages

```bash
git init
git add .
git commit -m "콘서 CBT"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

저장소 → **Settings → Pages** → Source를 **Deploy from a branch**, 브랜치 `main` / 폴더 `/ (root)` → Save.
1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다.

### Vercel

저장소를 import 하고 Framework Preset을 **Other**, Root Directory를 이 폴더로 두면 끝입니다.
빌드 명령은 비워 둡니다. 이후엔 `git push` 할 때마다 자동 반영됩니다.

## 주차 추가하기 (3~7주차)

**1.** `data/week03.js` 를 만듭니다. `week02.js` 를 복사해 고치는 게 빠릅니다.

```js
window.QUIZ_BANK = window.QUIZ_BANK || [];
window.QUIZ_BANK.push({
  week: 3,
  title: "예/복습 테스트",
  items: [
    { id: "w3-01", no: "1", type: "choice", tag: "주제",
      q: "문제 문장",
      options: ["보기1", "보기2", "보기3", "보기4"],
      answer: "보기1",
      why: "해설" }
  ]
});
```

**2.** `index.html` 아래쪽에 한 줄 더합니다.

```html
<script src="data/week02.js"></script>
<script src="data/week03.js"></script>   <!-- 추가 -->
```

이게 전부입니다. 홈 화면에 `3주차` 칩이 자동으로 생기고, `종합 (전체)` 범위에도 자동으로 들어갑니다.

### 문항 형식

| type | 필드 | 채점 |
|---|---|---|
| `choice` | `options[]`, `answer` | 맞으면 1, 아니면 0 |
| `multi` | `options[]`, `answers[]` | (맞게 고른 수 − 틀리게 고른 수) ÷ 정답 수 |
| `match` | `pairs: [[왼쪽, 오른쪽], ...]` | 맞은 짝 ÷ 전체 짝 |
| `order` | `seq: [순서대로]` | 자리를 맞힌 항목 ÷ 전체 |
| `short` | `accept: [정답, 허용표현, ...]` | 후보 중 하나와 맞으면 1 |

공통 필드는 `id`(고유), `no`(시험지 번호), `tag`(주제), `q`(문제), `why`(해설)입니다.
`q` 와 `why` 에는 `<b>` `<i>` `<br>` 을 쓸 수 있습니다. `<i>` 는 인용 블록으로 보입니다.

보기 순서 · 문항 순서 · 짝짓기 선택지 · 순서 배열 후보는 **앱이 매번 섞으므로** 신경 쓰지 않아도 됩니다.

`short` 는 조사나 어미가 붙어도 통과합니다 — 공백과 문장부호를 지우고 비교한 뒤,
정답이 답 안에 들어 있기만 하면 맞다고 봅니다. (`소멸성` → `소멸성이다` 통과)

## 쓰는 법

**범위** 주차를 골라서 (여러 개 선택 가능), 또는 `종합 (전체)` 로 전 범위

**방식**
- `학습 모드` — 한 문항씩 바로 정답과 해설을 보며 넘어갑니다
- `시험 모드` — 끝까지 다 푼 뒤 한꺼번에 채점합니다

**문항 수** 전체 / 10 / 20 (범위보다 큰 값은 자동으로 잠깁니다)

**오답만 풀기** 틀린 문항이 자동으로 쌓이고, 다시 맞히면 목록에서 빠집니다.

풀이 중 오른쪽 위 `3/7` 을 누르면 문항 목록이 열려 아무 문항으로나 건너뜁니다.
PC에서는 숫자키로 보기 선택, `←` `→` 로 이동, `Enter` 로 확인/다음이 됩니다.

기록(최근 · 최고 · 평균)과 오답노트는 그 사람 브라우저에만 저장됩니다.
푸는 사람마다 따로 쌓이고, 서버로 나가지 않습니다.

## 8주차 종합 대비

2~7주차 파일을 다 넣은 뒤 `종합 (전체)` + `시험 모드` + `전체` 로 돌리면
전 범위가 섞여 나옵니다. 틀린 것만 `오답만 풀기` 로 반복하면 됩니다.
